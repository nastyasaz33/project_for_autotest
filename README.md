# ToDo List

Консольное приложение на Python для управления личным списком задач: добавления, просмотра, удаления и изменения статуса выполнения.

## Требования

Для запуска программы необходим Python версии 3.8 или выше.

## Запуск

Скачайте или клонируйте проект, перейдите в папку с программой и выполните команду:

`python main.py`

## Использование

После запуска программы появится меню, в котором можно:

1. Просмотреть все добавленные задачи.
2. Добавить новую задачу.
3. Изменить статус задачи.
4. Удалить выбранную задачу.
5. Посмотреть статистику.
0. Завершить работу программы.

В программе реализована валидация пользовательского ввода, которая позволяет корректно обрабатывать некорректные данные и выводить сообщения об ошибках. Каждая задача содержит название и текущий статус выполнения.

## Класс ToDoList

Основная логика программы реализована в классе `ToDoList`.

Класс хранит список задач и предоставляет методы для просмотра, добавления и удаления задач, изменения их статуса и просмотра статистики.

Каждая задача хранится в виде словаря с названием задачи и её текущим статусом.

## Итоги

В результате создано консольное приложение для управления списком задач с использованием объектно-ориентированного программирования.

Программа позволяет выполнять основные операции со списком задач и отслеживать количество выполненных и невыполненных задач.

Для завершения работы программы необходимо выбрать пункт `0` в главном меню. После этого программа выведет сообщение о завершении работы и завершит выполнение.
